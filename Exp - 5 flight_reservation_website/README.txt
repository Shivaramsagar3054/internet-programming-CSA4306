SKYWAY FLIGHT RESERVATION SYSTEM — INTERNET PROGRAMMING LAB

HOW TO RUN
1. Extract flight_reservation_website.zip.
2. Open index.html in Chrome, Edge, or Firefox.
3. No installation or server is required for this demo.

FEATURES
- Flight search by origin, destination, date, passenger count, and cabin class
- Responsive flight results with sample fares and seat inventory
- Customer registration, login, and demo forgot-password flow
- Passenger details and seat selection
- Simulated UPI/card/net-banking payment selection (no payment is processed)
- Booking reference (PNR), ticket view/print, booking status, booking history
- Ticket cancellation and simulated refund record
- Customer feedback form
- Administrator panel to add/remove flights, inspect bookings/users/revenue, view feedback, export CSV
- Browser localStorage persistence

IMPORTANT LIMITATIONS
This is an educational front-end prototype. It does not connect to airline Global Distribution Systems or airline APIs. Availability and prices are sample data, not real-time. Authentication and data are stored in the browser and are not secure. Payment, password reset, email confirmations, refunds, and booking operations are simulated. Do not enter real passwords, identity numbers, or payment information. Tickets are not valid for real travel.

For a production implementation, add a backend, database, secure authentication, server-side authorization, airline/GDS integration, payment gateway, email service, input validation, audit logs, and privacy/security controls.
