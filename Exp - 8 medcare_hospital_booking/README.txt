MEDCARE HOSPITAL APPOINTMENT BOOKING - FRONTEND DEMO

Files:
- index.html: website layout and booking form
- style.css: responsive styling
- script.js: sample hospitals, specialties, doctors, filters, date/time slots, demo appointment creation and cancellation

How to run:
1. Extract the ZIP.
2. Keep index.html, style.css, and script.js in the same folder.
3. Open index.html in a browser, or use VS Code Live Server.
4. An internet connection is needed for the remote sample doctor photos and Google Fonts.

Important limitations:
This is a frontend educational prototype. Sample doctor/hospital data is hardcoded, and appointments exist only in JavaScript memory until the page is refreshed. It does not connect to real hospitals, real appointment systems, a database, authentication, SMS/email reminders, or a payment gateway. Do not enter real patient or medical data. A production healthcare service requires secure backend storage, access controls, encryption, audit logging, and appropriate healthcare privacy/regulatory review.
