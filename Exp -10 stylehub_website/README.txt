STYLEHUB FASHION E-COMMERCE WEBSITE
===================================

Files
-----
index.html  - Page structure and UI
style.css   - Responsive styling
script.js   - Product catalogue, search, filters, cart, wishlist, demo account, checkout and order history

How to run
----------
1. Extract stylehub_website.zip.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension in VS Code.
4. Internet access is needed for Google Fonts and the remote Unsplash product photos.

Included features
-----------------
- Responsive fashion storefront for women, men, kids and accessories
- Product catalogue with photos, categories, prices, ratings and customer review snippets
- Search, category filters, price filters and sorting
- Product details modal with size selection and a simple size guide
- Wishlist / saved pieces
- Shopping cart with quantity changes, remove item and subtotal
- Demo login and registration UI
- Demo checkout with address and payment-method selection
- Demo order confirmation and order history/status
- Flash-sale banner, promo code styling and newsletter signup
- Return policy and contact demo messages

Important limitations
---------------------
This is a front-end student project/demo. It does not include a server, database, real account security, real order email/SMS, actual shipment tracking, inventory synchronization, or payment processing. Account, cart, wishlist and orders are kept in page memory and reset on refresh. The payment options are illustrative only. For production use, connect a backend/database, secure authentication, a payment gateway, email/SMS services and a shipping provider.
