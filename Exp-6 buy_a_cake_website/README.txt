BUY A CAKE - FRONTEND WEBSITE

Files
- index.html: page structure and content
- style.css: responsive design and layout
- script.js: cake catalog, category filters, search, customization dialog, shopping bag and demo checkout

How to run
1. Extract the ZIP.
2. Keep index.html, style.css and script.js in the same folder.
3. Open index.html in a modern browser. For best results, use VS Code with the Live Server extension.

Notes
- Product photos are loaded from Unsplash, so an internet connection is needed for those images.
- This is a frontend demo. Login, inventory management, email confirmation, live delivery tracking and real payment processing need a backend and payment/email provider.
- Checkout is intentionally a demo and does not collect payment details or process payments.
