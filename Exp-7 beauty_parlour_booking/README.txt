GLOW STUDIO - BEAUTY PARLOUR APPOINTMENT BOOKING WEBSITE

Files:
- index.html: page structure and appointment form
- style.css: responsive salon-themed design
- script.js: service catalog, stylist profiles, date/time slot selection, demo booking and cancellation
- README.txt: setup notes

Run:
1. Extract the ZIP file.
2. Keep all files in the same folder.
3. Open index.html in a browser, or use VS Code Live Server.
4. Internet is needed for Google Fonts and remote Unsplash photos.

Demo limitations:
This is a frontend prototype. Appointment records are held in browser memory and disappear on refresh. Real-time shared availability, user authentication, admin management, email reminders, and payment processing require a backend/database and external service integrations. No payment is collected.
