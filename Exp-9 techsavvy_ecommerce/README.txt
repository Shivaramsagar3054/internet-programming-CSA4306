TECHSAVVY ELECTRONICS E-COMMERCE WEBSITE — FRONTEND DEMO

Files:
- index.html: page layout and components
- style.css: responsive styles
- script.js: sample product catalog, search/filter/sort, product details, cart, wishlist, demo checkout and order status tracking

Run:
1. Extract this ZIP.
2. Keep index.html, style.css, and script.js in one folder.
3. Open index.html in a browser, or use VS Code with Live Server.
4. Internet is required for remote sample product images and Google Fonts.

Demo limitations:
This is a frontend-only educational project. Product information is sample data. Cart, wishlist and orders exist in JavaScript memory and reset when the page is refreshed. Checkout does not process payments. Real registration/login, database storage, order email, secure payment, inventory, customer-specific recommendations, and persistent order tracking require backend and service integrations. Do not enter payment details or real account credentials.
